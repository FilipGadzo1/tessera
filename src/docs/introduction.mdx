# Tessera

A *tessera* is a single tile of a mosaic. Every component here is a tile; every project is a mosaic.

## Use it in a project

```css
/* your app's main stylesheet */
@import "tailwindcss";
@import "@tessera/ui/styles.css";
```

```tsx
import { Button } from "@tessera/ui";

<Button variant="solid" color="primary">Save</Button>
```

Theme with attributes on `<html>` (or any element — scopes nest):

```html
<html class="dark" data-primary="lapis" data-surface="slate">
```

Use the **Theme / Primary / Surface** switches in the toolbar to preview every combination.

For a custom brand, override the palette scale `--tsr-primary-50` … `--tsr-primary-950` (and/or
`--tsr-surface-0` … `--tsr-surface-950`) in an unlayered `:root`: every role — hover, soft, ring,
dark mode and the `primary-*` scale utilities — follows. Overriding `--primary` alone changes only
the resting color. Token names are shadcn-compatible (`--primary`, `--ring`, …), so utilities like
`bg-primary` work unchanged; the values are Tessera's.

- A nested `data-primary` scope rebinds `--tsr-primary-*`, so a `:root` primary-scale override
  does not reach inside it.
- There is no `.light` scope to switch a region back to light inside `.dark`.
- Card variants are `outlined` / `elevated` (MUI naming); Button and Badge use `outline`.

## Forms

Label, Field (FieldLabel, FieldDescription, FieldError, FieldItem), Fieldset, Input, Textarea,
Checkbox, Switch and RadioGroup. Wrap named Fields in `Form` for
submit-time validation — see **Examples / Sign-up form**.

## Overlays

Tooltip, Popover, Dialog, AlertDialog and Menu. Triggers carry no styles — compose them with
`render={<Button … />}`. See **Examples / Project card** for all of them in one card.

Overlays portal into `document.body`, so they follow the theme on `<html>` (the toolbar switches
set it there). A theme scope on an inner element does not reach a portalled overlay: pass
`container` (an element inside the scope) to the `*Content` part. Overlays sit on `--z-overlay`
(50) and `--z-tooltip` (60); give your app root `isolation: isolate` so its own z-indexes stay
below them.

## Navigation and feedback

Tabs, Accordion, Select, Toast (`Toaster` + `useToast()`), Avatar, Progress and Separator. Wrap the
app in `Toaster` once; any component inside calls `useToast().add({ title, type })`. See
**Examples / Settings** for all of them on one page. Toasts sit on `--z-toast` (70), above
overlays and tooltips.

## Data entry and display

Skeleton, Breadcrumb, Pagination (+ `getPaginationRange`), Table (+ `TableSortButton`), Slider,
NumberField, Combobox and Drawer (Tessera's sheet, `side` on the root). Skeleton, Breadcrumb,
Pagination and Table are server-safe. See **Examples / Orders** for all of them on one page: a
filterable, sortable, paged orders table with loading Skeletons and an order Drawer.

## Dates, toolbars and surfaces

Meter, ScrollArea, Toggle/ToggleGroup, Toolbar, PreviewCard, ContextMenu (reuses Menu's items),
Calendar/RangeCalendar and DatePicker/DateRangePicker (Select-styled triggers, no typed date
field). See **Examples / Editor** for all of them on one page: a "New post" card with a formatting
Toolbar, a Menubar, a ScrollArea body under a ContextMenu, an author PreviewCard, Publish/Embargo
date pickers and a character-count Meter.

## Forms and navigation

Collapsible, CheckboxGroup (with a parent "Select all" checkbox), Form (submit-time validation and
server `errors` keyed by Field name), OTPField, Autocomplete (suggestions that keep free text),
Menubar and NavigationMenu (a site header with shared, animated panels). See **Examples / Checkout**
for most of them on one page: a NavigationMenu header, a Form with a phone check (OTPField), a city
Autocomplete, delivery options (CheckboxGroup), a Collapsible promo code that the fake server can
reject through `errors`, and an order summary.

## Dates and the app shell

DateField (typed date segments), an `editable` DatePicker (type the date or pick it), form
participation for every date control (DatePicker submits `YYYY-MM-DD`, DateRangePicker
`{ start, end }`, under the Field `name`) and the Sidebar family (SidebarProvider with Ctrl/⌘+B,
icon-collapsible, a Drawer on phones). See **Examples / Dashboard**: a Sidebar with a workspace Menu
and account Menu, a top bar with a Breadcrumb and a command palette, stat Cards with Progress and
Meter, a filter Form with date controls, and a Table.

## Ranges, commands, trees and carousels

DateRangeField (two typed dates in one field) and an `editable` DateRangePicker, Command and
CommandDialog (a ⌘K command palette), Tree (an APG treeview with keyboard navigation, typeahead and
selection) and Carousel (scroll-snap slides with previous/next, dots and optional rotation). See
**Examples / Files**: a Sidebar with a folder Tree, a Table of the open folder's files, a Modified
date-range filter, an image-preview Carousel and a ⌘K command palette that goes to a folder, creates
one or toggles the sidebar.

## Shortcuts, panels, steps, ratings and colour

Kbd and KbdShortcut (keycaps that read ⌘ K on a Mac and Ctrl K elsewhere), Resizable (APG
window-splitter panels with collapsible panes), Stepper (a wizard's step list with complete and error
states), Rating (stars on a radio group, with half steps and a read-only display), ColorPicker and
ColorPickerPopover (an area, hue and alpha sliders, a text field and swatches), and the colour helpers
(`parseColor`, `contrastRatio`, `readableForeground`, …). See **Examples / Theme Studio**: a Stepper
wizard in a collapsible Resizable panel, colour pickers gated by a WCAG contrast Badge, a live
preview themed with custom properties, a Rating, and Ctrl/⌘+S and Ctrl/⌘+J shortcuts with KbdShortcut
hints.

## Times, tags, files and data tables

TimeField (typed time segments) and TimePicker (the same field with a list of time slots), TagsInput
(chips with add, reject and remove, announced), FileUpload (a native file input with a drop zone,
validation and per-file progress) and DataTable (`useDataTable` for sorting, multi-sort, paging, row
selection and column visibility, rendered by DataTable, DataTableColumnsMenu and DataTablePagination).
See **Examples / Events admin**: a sortable, selectable, paged events table with search and a Columns
menu, and a drawer form that combines a DatePicker, a TimePicker, a TagsInput and a FileUpload with an
upload per attachment.

## Stack

React 19 · Base UI · Tailwind CSS v4 · cva + tailwind-merge · tsdown · Vitest browser mode ·
Storybook 10 · Biome — design language inspired by PrimeVue (token tiers, palette presets) and
Material UI (variant × color, elevation).
